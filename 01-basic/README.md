
# Shell Scripting Practice

## Basic Shell Script Commands

This repository contains my practice for shell scripting basics.

## Script included
- om.sh

## What this script does:
- Prints messages using echo( echo " Hello")
- Creates a folder using mkdir -p(-p is used to create parent directories if they don’t exist)
- Creates a file using shell script

## How to run:
chmod 764 om.sh (provide permission for Read + Write + Execute)


./om.sh(run a file from the current directory)
