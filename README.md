
# Linux Automation Toolkit 🚀

This repository contains a collection of lightweight automation scripts designed to simplify common Linux system administration tasks.

The focus of these scripts is to demonstrate practical automation scenarios commonly used in DevOps and system operations.

---

## 📌 Overview

The repository is structured into multiple modules, each addressing a specific operational requirement such as user management, package installation, input handling, and backup automation.

These scripts are designed to be simple, reusable, and easily adaptable for real-world environments.

---

## ⚙️ Key Capabilities

- 🔹 Automated user provisioning  
- 🔹 Package installation and system setup  
- 🔹 Input-driven script execution  
- 🔹 Modular scripting using functions  
- 🔹 Task automation using loops  
- 🔹 Backup and archiving operations  

---

## 📁 Structure

| Directory | Description |
|----------|------------|
| 01-basic | Script structure and execution |
| 02-variable | Handling dynamic values |
| 03-userinput-argument | Processing runtime inputs |
| 04-create_user | User provisioning automation |
| 05-install_package | Package installation workflow |
| 06-check_userexits | User validation logic |
| 07-functions | Modular and reusable scripts |
| 08-loops | Iterative automation |
| 09-backup | Backup and archive automation |
